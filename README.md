# Operating System Assignments

Welcome to my **Operating System (OS) Assignments** repository. This repository contains practical assignments, programs, and implementations completed as part of my Third Year B.Tech Computer Engineering coursework.

The main objective is to understand Operating System concepts through hands-on programming, Linux commands, and shell scripting.

## 📚 Topics Covered

- Linux Commands and Basic Administration
- Shell Scripting (Bash)
- Process Management
- CPU Scheduling Algorithms
- Process Synchronization
- Deadlock Management
- Memory Management
- File System Management
- Disk Scheduling Algorithms
- System Monitoring and Utilities

## 🛠️ Technologies & Tools

- **Operating System:** Linux
- **Programming Languages:** C, Bash Shell Scripting
- **Editor:** VS Code / Vim
- **Terminal:** Linux Terminal
- **Platform:** Linux Environment

*Note: The repository structure will be updated as more assignments are added.*

## 🎯 Objectives

- Understand the fundamentals of Operating Systems.
- Gain practical experience with Linux commands.
- Develop shell scripting and system programming skills.
- Implement and analyze different OS algorithms.
- Explore process, memory, and file management concepts.
